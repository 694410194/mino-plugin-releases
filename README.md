# Mino 推荐插件发布包

这里只放 Mino 推荐的 DSH 插件压缩包（`.tgz`），每个版本一个 release，例如 `plugins-v0.1.0`。

安装：下载对应压缩包后运行

```
dsh plugin --profile desktop add 下载的.tgz路径
```

重启 Mino 后生效。各插件的说明见 [使用指南](https://mino.baby/docs/)。

- 插件均派生自社区开源项目，原许可与署名随包保留在各自的 `LICENSE`、`NOTICE` 和 README 中。
- Mino 桌面安装包不在这里，见 [mino-releases](https://github.com/694410194/mino-releases)。
